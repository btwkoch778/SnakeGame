# Snake Game

A simple Snake game developed with C# and Windows Forms.

## Features

- Control the snake with the arrow buttons or keyboard arrow keys.
- Eat the food to increase the snake's length and score.
- The game ends when the snake touches the game panel's border or itself.
- Start a new game by pressing any arrow button after the game ends.
- The score resets when a new game starts.

## Run

1. Open `SnakeGame.slnx` in Visual Studio 2022 or a newer version.
2. Make sure the .NET 8 SDK is installed.
3. Press **F5** to build and run the game.
